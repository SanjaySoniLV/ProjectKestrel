Data & Preview

Keep full-size RAW previews in the .kestrel/culling_TMP folder so later loads are faster. Turn off to save disk space; previews are then made again each time.
Display only: how strongly Kestrel's calculated exposure boost is applied to preview imagery (grid & scene-dialog export thumbnails and the RAW zoom). 0% shows the uncorrected export; 100% matches the processed bird crop. The same slider is in the scene viewer. Does not affect analysis or the baked crop.
Automatically save ratings, tags, and scene changes. When disabled, you'll see a Save/Revert workflow.
Both scores are computed during analysis (analysis version 3.0) and stored, so switching is instant — no re-analysis. Both judge focus/sharpness only, not whether a photo is "good". The original model is the default again from Arctic Tern (FP 1); the newer model is kept so you can compare. Folders analysed before 3.0 only have the legacy score until upgraded.
Bird crops are always indexed for smart search. This also indexes each photo's whole frame so scene queries work ("bird on a wire", "two birds", "wide landscape"). Adds about 0.1–0.2 seconds per photo on the CPU.
Analyses the JPEG preview stored inside each RAW file instead of decoding the sensor data. Much faster per photo; the sharpness score is largely unaffected, but exposure/highlight recovery is skipped and quality depends on the preview size your camera writes (some older bodies embed only a small one). RAWs without a usable preview are still decoded. Applies to analyses started after you change it, on this computer only — Cloud Compute always decodes RAW.
Where the species and search models run when GPU analysis is on. Auto: GPU on Windows, CPU on macOS, where the GPU path does not support these models. Applies to the next analysis.
Enhanced GPU Performance uses extra GPU software made for your graphics hardware to speed up analysis. Setup downloads that software from Windows and tests Kestrel’s models on your computer. If it fails, Kestrel uses standard GPU acceleration.

⚙ Review settings
What subjects does this shoot contain?
Including other wildlife names 1,200+ non-bird species — squirrels, deer, bears and more. This has a small impact on total processing time.
Should Kestrel identify the bird species?
Kestrel names each bird from the world's ~11,000 bird species, narrowed to the region below. Skipping it makes analysis faster; finding your subjects and scoring their quality work exactly the same either way.
A narrower region list makes identification more accurate. Change your default regions in Settings → Species & Region.
How many subjects should Kestrel analyze in each image?
Every extra subject adds processing time. Lower this for flock shots where you only care about the closest few birds.
More options ▾
Performance & behavior
How many photos to load in advance so analysis keeps moving (1–5). Lower this if your computer slows down too much during analysis.
Finding subjects
Accurate is the right choice for almost every shoot. Fast uses a smaller model that finishes sooner but misses distant and partly-hidden birds.
How sure Kestrel must be that it found an animal before analyzing it (0.10–0.99). Lower values find more subjects.
⚠ Kestrel suggests 0.15. Higher values miss real subjects.
Exposure & grouping
Controls how strongly Kestrel corrects bird exposure in the analyzed crops. Balanced is recommended for most images.
Images captured within this many seconds of each other are treated as the same burst/scene.
Forces a scene break whenever this much time passes between two shots, even if they look alike — useful when a long session against the same background would otherwise become one huge scene. 0 turns it off.
Thumbnails
Size of the cached analysis thumbnails, in pixels on the longest side. Larger looks sharper but uses more space in the .kestrel folder.
0.75 means 75% JPEG quality. Lower values reduce file size with more visible compression artifacts.

⚠ Confirm destructive re-analysis

The following folders will have .kestrel data permanently deleted before re-analysis. This wipes all user-written data (ratings, accept/reject decisions, scene names) for the affected folders.

    This cannot be undone. Other queued folders (that don't need re-analysis) are unaffected.

    ⚠ Delete Kestrel analysis data?

    The following data will be permanently deleted from this folder's .kestrel/ directory:

    • Star ratings
    • Accept / Reject culling decisions
    • Scene names
    • Exported derivatives and thumbnails

    This cannot be undone. Photos in the folder are not touched.

    Would you like to share anonymous usage data to help improve the app? This is completely optional and you can change your mind at any time.
