⚙ Review settings
What subjects does this shoot contain?
Including other wildlife finds 1,200+ non-bird species — squirrels, deer, bears and more. It adds noticeable time per image.
Does this shoot contain North American birds?
Kestrel's bird species classifier only recognizes North American birds. Skipping it makes analysis faster; finding your subjects and scoring their quality work exactly the same either way.
How many subjects should Kestrel analyze in each image?
Every extra subject adds processing time. Lower this for flock shots where you only care about the closest few birds.
More options ▾
Performance & behavior
Number of images to read ahead to sustain the processing queue (1–5). Lower this if your computer slows down too much during analysis.
Finding subjects
Accurate is the right choice for almost every shoot. Fast uses a smaller model that finishes sooner but misses distant and partly-hidden birds.
How sure Kestrel must be that it found an animal before analyzing it (0.10–0.99). Lower values find more subjects.
⚠ Suggested value: 0.15. Higher thresholds miss real subjects — modern wildlife detectors are calibrated for low values.
Exposure & grouping
Controls how strongly Kestrel corrects bird exposure in the analyzed crops. Balanced is recommended for most images.
Images captured within this many seconds of each other are treated as the same burst/scene.
Thumbnails
Long-edge pixel width for cached analysis thumbnails. Higher values look sharper but increase .kestrel storage.
0.75 means 75% JPEG quality. Lower values reduce file size with more visible compression artifacts.

⚠ Confirm destructive re-analysis

The following folders will have .kestrel data permanently deleted before re-analysis. This wipes all user-written data (ratings, accept/reject decisions, scene names) for the affected folders.

    This cannot be undone. Other queued folders (that don't need re-analysis) are unaffected.

    ⚠ Delete Kestrel analysis data?

    The following data will be permanently deleted from this folder's .kestrel/ directory:

    • Star ratings
    • Accept / Reject culling decisions
    • Scene names
    • Exported derivatives and thumbnails

    This cannot be undone. Photos in the folder are not touched.

    💬 Send Feedback

    📊 Help Improve Project Kestrel

    Would you like to share anonymous usage data to help improve the app? This is completely optional and you can change your mind at any time.

    What would be shared (anonymously):

    • Number and size of images analyzed
    • File formats used (e.g. CR3, JPG)
    • Analysis duration
    • App version and OS type

    What is never shared:

    • Filenames, folder paths, or image content
    • Any personally identifiable information

    Your machine is identified only by a random ID — no device name, username, or IP address is stored or sent.
