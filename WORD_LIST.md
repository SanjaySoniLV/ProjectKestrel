# Word list

One word for one idea in everything a user reads: buttons, dialogs, tooltips, status text,
tutorials and What's New. Use these words in new text, and fix old text to match when you touch
it. A translation should start from this list.

Write user-visible text in plain English. Headings, dialog titles and menu items are in sentence
case ("Folder settings", not "Folder Settings"); a few older main-window buttons are still in
title case and change when their screen is redesigned.

| Idea | Use | Don't use |
|---|---|---|
| A photo you keep | **Accept**, accepted | Keep, green label, pick |
| A photo you drop | **Reject**, rejected | Discard, delete (unless files really are deleted) |
| No decision yet | **Undecided** | Unrated (only for a photo with no stars), reset, none |
| The 0–1 score Kestrel gives each photo | **Quality**, written `Quality 0.865` (two decimals on scene cards) | Q, Q 0.86, sharpness score, max quality |
| How sure the species ID is | **Species match**, written `Great Egret (0.79)` | Quality, confidence (in new text) |
| 1–5 stars | **Star rating** | Rating score |
| A burst of photos of one subject | **Scene** | Group, cluster, burst |
| The screen that shows one scene | **Scene viewer** | Scene dialog, scene view |
| The bulk-cull window | **Culling Assistant** | Culling mode |
| The format of a folder's analysis | **Analysis version** (e.g. "analysis version 3.0") | Pipeline version, Kestrel version |
| The app release | **Project Kestrel v7.2.0** | Version: …, build |
| Per-folder options | **Folder settings** | Folder options, change settings |
| The per-folder menu | **Folder actions** (the ⋯ menu) | Folder menu |
| Putting folders in the sidebar or the Analyze list | **Add folders** | Load folders, open folders |
| Brightening the preview | **Exposure adjustment** | Exp comp, brighten |
| Writing XMP files | **Write photo metadata** | Export XMP, sidecars (in headings) |
| Sharing an outing online | **Share with Perch** | Upload to Perch, publish |
| Analysis on our servers | **Cloud Compute**, cloud analysis | Modal, remote GPU |
