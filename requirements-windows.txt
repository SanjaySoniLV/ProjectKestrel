# Windows CI build requirements
#
# Identical to requirements.txt except we use onnxruntime-windowsml instead of
# the CPU-only onnxruntime package. onnxruntime-windowsml is a normal ONNX Runtime
# build that bundles the DirectML execution provider, which gives GPU acceleration
# on any DX12-compatible GPU (NVIDIA, AMD, Intel), and can also load the vendor
# execution providers that Windows ML downloads for the opt-in "enhanced GPU
# performance" mode (analyzer/kestrel_analyzer/ml/enhanced_gpu.py). DirectML stays
# the default; the vendor path is off until the user runs its setup. The package
# conflicts with onnxruntime / onnxruntime-directml (same `onnxruntime` module
# name), so only one may be installed at a time; uninstall the others first.
#
# Local dev installs still use requirements.txt (CPU-only) to avoid dragging
# GPU drivers into the dev loop. This file is referenced by the Windows build
# in .github/workflows/main.yml.

# Core ML/AI Dependencies
# The wasdk-* packages (Windows App SDK Python bindings, used only by the enhanced GPU
# mode) pin onnxruntime-windowsml to exactly 1.25.2, so these three move together.
# Benchmarked: DirectML speed in 1.25.2 matches onnxruntime-directml 1.24.4.
